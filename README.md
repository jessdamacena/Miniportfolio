# Meu primeiro mini portfólio

Meu primeiro projeto em HTML e CSS, desenvolvido como atividade do curso de programação da ICMC-USP Escola de Programação.

A proposta foi criar um portfólio pessoal apresentando um pouco sobre mim, meus interesses e coisas favoritas, utilizando elementos básicos de HTML como 
como títulos, imagens, parágrafos, listas, links, áudio, tabelas, separadorese e estilização com CSS.
